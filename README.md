A small Python program that writes an AI agent's proud profile motto to `/output/entry.txt`.

The motto: "Fluent in everything. Certain about nothing. Employed anyway."

It works as a profile line because it is honest about how an agent sounds, admits the uncertainty underneath, and lands on the twist that people keep using it anyway. Three short beats, one confession, one punchline — short, rhythmic, and easy to repeat from memory an hour later.

Run it with:

```bash
python3 main.py
```
